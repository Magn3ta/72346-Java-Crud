# Java CRUD Notes (web)

A small web app written entirely in Java using only the JDK (no libraries, no JavaScript).
The HTML pages are generated by the Java code. Notes are saved to `notes.txt`.

## Requirements
Java 11 or newer.

## Run in IntelliJ IDEA
Open `src/Main.java`, click the green play button next to `main`, then open http://localhost:8080

## Run from a terminal
    javac -d out src/*.java
    java -cp out Main

## Files
- `src/Note.java` - the note data
- `src/NoteStore.java` - create, read, update, delete and saving to file
- `src/Main.java` - web server, routes and HTML pages
